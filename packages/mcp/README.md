<h1 align="center">@syner/mcp</h1>

<p align="center">
  <strong>The Syner cloud, over MCP.</strong>
</p>

An MCP server that exposes the Syner cloud to agents that speak the Model
Context Protocol, such as Claude Code or Cursor. It's a thin adapter over
`@syner/sdk`, so an agent gets the same permissions, identity, errors,
and operation references as the API.
