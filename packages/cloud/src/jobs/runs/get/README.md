<h1 align="center">get</h1>

<p align="center">
  <strong>Read one run.</strong>
</p>

Returns the run with its events and reference.

## Example

```ts
const run = await syner.jobs.runs.get({ id })
```

In the CLI: `syner jobs runs get <id>`.
