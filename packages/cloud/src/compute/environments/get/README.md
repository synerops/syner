<h1 align="center">get</h1>

<p align="center">
  <strong>Read one environment.</strong>
</p>

Returns an environment and its status.

## Example

```ts
const env = await syner.compute.environments.get({ id })
```

In the CLI: `syner compute environments get <id>`.
